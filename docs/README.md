## Doc rules

- Markdown + Mermaid only. No images of diagrams.
- Keep docs close to the code. A code comment beats a doc; a doc beats a wiki.
- Deprecate aggressively. Delete stale docs; don't mark them "old".
- No boilerplate. If a section has nothing to say, leave it out.
- One topic, one place. Link to it instead of repeating it.
